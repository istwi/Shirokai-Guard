# Entrega 0.2.0-alpha.1

Minecraft Java 1.21.1 · Fabric · Java 21 · somente servidor.

Instale **shirokai-guard-0.2.0-alpha.1.jar** em `mods/`. Fabric Loader 0.17.2+ e Fabric API 0.116.18+1.21.1 são necessários. Clientes não precisam do Guard. O ZIP do projeto, sources.jar e fixtures de teste não são mods instaláveis de produção.

Esta versão acrescenta `/sg menu`, templates opcionais com confirmação, configuração de permissões/defaults/interface, visualização limitada de bordas, cache espacial e verificações de login/respawn/movimento do servidor. Para começar, use `/sg wand`, selecione dois cantos, `/sg define spawn` e configure flags ou aplique um template com prévia. Os templates não são necessários para operar o mod.

[Validação e limitações](VALIDATION.md), [instalação e comandos](../README.md), [integrações](INTEGRATIONS.md). Continua alpha: 100 jogadores internos não equivalem a 100 clientes remotos; raid completa e economia de produção não foram jogadas. `pokemon-breeding` não é anunciada sem API real no Cobblemon original.

Os artefatos e SHA256SUMS são preparados localmente em `build/`. Não houve publicação de ambiente, commit remoto ou release GitHub nesta entrega.
